Importer des joueurs

Instructions d'importation :

Importez des joueurs à partir d'un fichier XLSX. Le fichier doit contenir exactement les colonnes suivantes :

  • Prénom: Prénom du joueur (obligatoire)
  • Nom: Nom du joueur (obligatoire)
  • Position: Position du joueur, doit être l'une des suivantes : Attaquant, Défenseur, Gardien, Milieu (obligatoire)
  • Équipe: Équipe du joueur (obligatoire)
  • Âge: Âge du joueur, doit être un nombre positif (obligatoire)

Assurez-vous que toutes les cellules contiennent des données valides. Les lignes avec des données manquantes ou invalides seront rejetées.

Important : En cas d'erreur lors de l'importation, veuillez vérifier que :

  1. Toutes les colonnes requises sont présentes
  2. Aucune cellule n'est vide (toutes les données sont obligatoires)
  3. La position est exactement l'une des valeurs attendues (Attaquant, Défenseur, Gardien, Milieu)
  4. L'âge est un nombre entier positif
